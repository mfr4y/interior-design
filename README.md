# Site d'architecte intérieur


### Introduction
> L'objectif de ce site est de présenter le travail d'un architecte d'intérieur simplement en premier projet concret dans le cadre du programme "La Toile" de EMLyon.

---
### Stack technique
> Ce site est monté en **HTML/CSS natif** et ne possède aucune base de données. Il est nécessaire d'avoir un accès à internet pour avoir les polices d'écritures mises sur le site via Google Fonts.

---
### Suivi d'apprentissage
> Durant la réalisation de ce premier projet, j'ai pu apprendre de nombreuses bases en : 
> - HTML natif
> - CSS natif nottament les bonnes utilisations de margin, padding, flexbox, grilles, boutons, glassmorphism ou encore la gestions d'images
> - Intégration de services externes CSS (fonts, icones, ...)
